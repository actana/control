# Support

Looking for help? Here's where to go — choosing the right channel gets you an answer fastest and keeps the issue tracker actionable.

| I want to… | Go to |
|---|---|
| Ask a question / get help using the project | [GitHub Discussions – Q&A](https://github.com/actana/control/discussions) |
| Report a reproducible bug | [Bug report form](https://github.com/actana/control/issues/new?template=1-bug-report.yml) |
| Propose a feature | [Feature request form](https://github.com/actana/control/issues/new?template=2-feature-request.yml) |
| Report a security vulnerability | [Private reporting](https://github.com/actana/control/security/advisories/new) — never a public issue |
| Read the docs | [docs/](docs/) |

Issues opened as support questions will be converted to Discussions. Maintainers provide best-effort support; there is no guaranteed response time for questions (bug triage SLAs are in [CONTRIBUTING.md](CONTRIBUTING.md)).

# Changelog

All notable changes to this project, newest first.

## 0.1.0 — unreleased

Core tarballs are published as `actana-core-<version>-<target>.tar.gz`. This is
the first published release of the Core tarball; no earlier asset name was ever
released, so no download URL changes.

If you installed a Harness from a locally built tarball before this release, run
`actana setup` once — it removes the old `actana-harness.service` user unit and
installs `actana-core.service`. Your data in `~/.local/share/actana` and
`~/.config/actana` is untouched; those paths do not change. Re-pairing with the
Panel is not required.

## Before 0.1.0

The fork this repository started from, kept because it explains the state a
working clone is in. None of it was released under a version number from here.

- 🏷️ **rebrand to Actana Control** — the app, the package (`actana-control`),
  the macOS bundle id (`ai.actana.control`), and the packaged artifacts all
  carry the new name. The userData directory moves to `Actana Control`, so an
  existing install starts with an empty database: no projects, sessions, saved
  token, or settings. Move the old directory across manually (copy, don't
  symlink — SQLite opens it exclusively) if you want that state back.
  The app icon and the in-app wordmark now carry the Actana mark, sourced
  from the Actana brand assets — the Mission Control robot is gone.
- 🔌 **auto-update disabled** — no update check, download, or dialog, and no
  outbound release check at startup. `electron/update-manager.ts` stays in the
  tree as a stub behind `AUTO_UPDATE_DISABLED`; the Settings → General update
  UI is hidden behind `AUTO_UPDATE_UI_ENABLED`. Re-enable is those two flags
  plus a `build.publish` URL once `control.actana.ai` is serving artifacts.
- 💥 **`MC_*` environment variables are now `AC_*`** — one wire break, no
  compatibility shim. Anything setting `MC_USER_DATA_DIR`, `MC_HARNESS_*`,
  `MC_CORE_LINK_*`, or `MC_DEV_*` must be updated; an installed remote Core
  needs its systemd unit or launchd plist regenerated by re-running the
  install.
- ✨ make native question popups, sandboxes, and push-to-talk standard always-on features
- ✨ add opt-in "multiplayer pets": see teammates' Mission Pets along the bottom when you're both working on the same git repo (off by default; only a one-way hashed repo id + your pet's name/species are ever sent — no repo URL, path, or identity)
- 🐛 fix packaged macOS app startup when the bundled server lives inside app.asar
